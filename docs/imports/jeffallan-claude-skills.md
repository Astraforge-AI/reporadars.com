## Реальная проверка Antigravity

`agy --version`: 1.1.27. `agy models` успешно возвращает список, включая `gemini-3.8-flash-medium`. Однако и изолированный permission-canary, и отдельный обычный CLI с коротким запросом без репозиторного содержимого возвращают:

```text
Eligibility check failed: Your current account is not eligible for Antigravity.
```

Дополнительный текст ошибки предлагает проверить возраст. В обоих результатах `status=ERROR`, `num_turns=0`, все token counters равны нулю. Полученный список моделей сам по себе не подтверждает право аккаунта выполнять запросы. Фактическую причину ограничения на стороне Google этот импорт не устанавливает.

Официальные рекомендации: [Antigravity FAQ](https://antigravity.google/docs/faq#why-is-my-age-unverified), [проверка возраста в Google Account](https://myaccount.google.com/age-verification). Верификацию пользователь выполняет самостоятельно; возраст/документы/пароли не запрашивались, ограничения не обходились.

Чужие инструкции модели не передавались. Проба запрета инструментов остановилась до model turn, поэтому запрет **ещё не подтверждён фактическими tool-denial events**. Исходные настройки CLI не изменялись; OAuth-файл использовался только самим официальным CLI, в изоляции через read-only bind, без чтения/копирования его содержимого агентом.

## Поправка загрузчика в отдельной копии

Первоначальный загрузчик отклонил `assets/social-preview.png` (634 295 байт) из-за лимита 512 KiB, хотя картинка находится вне всех пакетов скиллов. В отдельной рабочей копии подготовлен двухпроходный вариант:

1. Проверка **всех** ZIP-путей, типов, дубликатов, wrapper и суммарного объявленного размера.
2. Чтение только каталогов найденных скиллов и корневой лицензии, с прежними per-file, CRC и общими лимитами. Корневой `SKILL.md` по-прежнему включает весь репозиторий.

Лимиты безопасности не повышались. Именно этой кандидатной версией сформирован отчёт. Исправление прошло независимое Astra-ревью и `go test -race ./...`, `go vet ./...`; исходная рабочая версия приложения не перезаписана. Интеграция кандидатной правки остаётся отдельным шагом: существующий Go importer уже был незакоммиченным baseline текущей задачи.
